# Licensing

The repository default license is `GPL-2.0-only`.

Use these SPDX headers in newly added source files unless a specific subtree
needs another compatible license.

Rust:

```rust
// SPDX-License-Identifier: GPL-2.0-only
```

C / C++ / headers:

```c
/* SPDX-License-Identifier: GPL-2.0-only */
```

Shell:

```sh
# SPDX-License-Identifier: GPL-2.0-only
```
